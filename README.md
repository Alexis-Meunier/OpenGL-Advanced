# POGLA Project

A real-time OpenGL 4.5 scene in C++20: a tessellated terrain with water waves, grass, a day/night sky, glowing lights with bloom, and a bunny that explodes.

## Features

- **Terrain**: a heightmap generated by a compute shader, with tessellation shaders adding detail.
- **Water**: tessellated waves animated by a compute shader, with ripples. Wind speed and direction drive the waves.
- **Grass**: blades built by a geometry shader.
- **Skybox**: changes with the time of day, which also moves the sun (a directional light).
- **Glowing lights**: emissive point lights that move.
- **Bloom**: compute shaders downsample and upsample the bright parts of the image, then a composite pass blends them back in.
- **Exploding bunny**: a bunny mesh, blown apart by compute and geometry shaders.

## Requirements

- A GPU and driver that support OpenGL 4.5 core
- `g++` with C++20 support
- GLEW and freeglut, plus `pkg-config`

On Debian/Ubuntu:

```sh
sudo apt install g++ make pkg-config libglew-dev freeglut3-dev
```

## Build and run

```sh
make
./main
```

Start `./main` from the repository root, because shaders are loaded from `shaders/` relative to the current directory. Run `make clean` to delete the build files.

## Controls

| Input | Action |
|-------|--------|
| Right mouse drag | Orbit the camera |
| Left mouse drag | Pan the camera |
| Mouse wheel | Zoom in and out |
| `w` / `s` | Raise / lower wind speed (0–12 m/s) |
| `a` / `d` | Turn wind direction |
| `+` / `-` | Move time of day forward / back |
| `7` / `8` | Add / remove inner tessellation divisions |
| `4` / `5` | Add / remove outer tessellation divisions |
| `b` | Toggle bloom |
| `e` | Restart the bunny explosion |
| `Esc` | Quit |

## Project layout

```
includes/   headers
src/        C++ sources (app, scene, camera, lights, bloom, ...)
shaders/    GLSL shaders, one folder per effect
```
